real-transfer 저장소 업로드용 최종 파일입니다.

1) 이 ZIP을 압축 해제합니다.
2) 압축 해제된 폴더 안의 파일/폴더 전체를 GitHub real-transfer 저장소 루트에 업로드합니다.
3) 같은 이름의 파일은 덮어씁니다.
4) 업로드 후 GitHub Actions > Build Windows EXE에서 빌드 결과를 확인합니다.
5) 성공하면 Artifacts > TransferChecklist-Windows에서 EXE를 받습니다.

중요: .github 폴더가 포함되어 있으므로 숨김폴더까지 함께 업로드해야 합니다.
